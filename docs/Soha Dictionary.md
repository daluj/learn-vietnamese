# How to use Soha Dictionary
Soha Dictionary is a free online Vietnamese dictionary that provides translations from English to Vietnamese and Vietnamese to Vietnamese. It is a useful tool for foreigners who are learning Vietnamese or who need to translate Vietnamese text.

**English-Vietnamese**

**To translate from English to Vietnamese, follow these steps:**

1.  Go to the Soha Dictionary website.
2.  In the search bar, type the English word or phrase you want to translate.
3.  Click the “Translate” button.
4.  The Vietnamese translation will appear below the English word or phrase.

**Vietnamese-Vietnamese**

**To translate from Vietnamese to Vietnamese, follow these steps:**

1.  Go to the Soha Dictionary website.
2.  In the search bar, type the Vietnamese word or phrase you want to translate.
3.  Click the “Translate” button.
4.  The Vietnamese translation will appear below the Vietnamese word or phrase.

Additional features**

Soha Dictionary also offers a number of additional features that can be helpful for foreigners learning Vietnamese. These features include:

*   Pronunciation: Soha Dictionary provides audio recordings of Vietnamese words and phrases, which can help you learn how to pronounce them correctly.
*   Example sentences: Soha Dictionary provides example sentences for each word or phrase, which can help you understand how it is used in context.
*   Word of the day: Soha Dictionary has a “Word of the day” feature that provides a new Vietnamese word or phrase with its translation and an example sentence.

**Conclusion**

Soha Dictionary is a comprehensive and easy-to-use resource for foreigners who are learning Vietnamese. It is a valuable tool for anyone who needs to translate Vietnamese text or who wants to learn more about the Vietnamese language.

**Additional tips**

*   If you are not sure how to spell a Vietnamese word or phrase, you can use the “Search by typing” feature to find it.
*   You can also use the “Sounds like” feature to find words that sound similar to the word or phrase you are looking for.
*   If you are looking for a specific type of translation, you can use the “Special dictionaries” feature to find a dictionary that specializes in that area.
