# **– Đàn:**

* ### Instrumental instruments frequently include a string or keyboard to perform music, and this classification is used to present them.: **đàn** piano *(piano)*, **đàn** ghita *(guitar),….*

### **Đàn** piano

### (**The** piano)

### -> In sentence: Bé Maria thích chơi **đàn piano**

### (Maria likes playing **piano**)
